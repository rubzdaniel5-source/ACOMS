# Flight Catering Requirements

## Flight Data
Flight number, date, aircraft registration/type, departure/arrival, sectors, passenger count, cabin configuration, catering station and catering status.

## Catering Status
Potential states: NOT_STARTED, PLANNED, IN_PREPARATION, READY, DISPATCHED, LOADED, COMPLETED, EXCEPTION.

## Integrations
Keep the model provider-neutral so scheduling and passenger/operations systems can be integrated later.
