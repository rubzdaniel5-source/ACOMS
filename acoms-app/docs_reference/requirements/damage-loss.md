# Damage and Loss Requirements

## Damage Lifecycle
`REPORTED → UNDER_REVIEW → ASSESSED → REPAIR → RETURNED_TO_SERVICE`

Alternative: `ASSESSED → RETIRED → DISPOSED`.

Capture equipment, quantity/item, date, station/location, reporter, reason, condition, assessment, action, disposition and evidence where needed.

## Loss Lifecycle
`REPORTED → INVESTIGATION → RECOVERED`

or:
`REPORTED → INVESTIGATION → CONFIRMED_LOSS → CLOSED`.

Capture equipment, quantity/item, last known location, date/time, reporter, circumstances, investigator, disposition, approval where required and audit history.

## Rules
Damage and confirmed loss must create traceable inventory effects. Recoveries must restore inventory through a traceable transaction. Sensitive actions require authorization.
